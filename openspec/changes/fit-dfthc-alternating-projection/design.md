## Definitions

Let `n = 76` and `P = n(n + 1)/2 = 2,926`. `H = shifted_target(tei, shift)` is
the `P × P` pinned pair target. Rows `X ∈ R^{L×P}`, with `L = R·C`, follow
the existing convention:

`X_(r,c) = Σ_b w_(r,b,c) f_(r,b)`, `f_(r,b) = svec(u_(r,b) u_(r,b)ᵀ)`, `‖u‖ = 1`.

`svec` and `symmetric_matrix` are the existing √2-scaled maps, so
`⟨svec(A), svec(B)⟩ = tr(AB)`. The residual reported in mHa is
`1000 · direct_residual(H, X)`.

## Precomputation (once per lane)

Compute the eigenpairs of `H`. Keep the `L` largest positive eigenvalues
`λ_k` with vectors `v_k`, and set `Y = diag(√λ) Vᵀ` (`L × P`). Record
`rank_lower_bound` for `L`. It is the floor of this method, 6.68 mHa at
`L = 360`.

## One sweep

1. **Procrustes.** Compute the SVD `X Yᵀ = U Σ Vᵀ`. Set `Q = U Vᵀ` and
   `Z = Q Y`.
2. **Weights, per group `r`.** Let `F_r` be the `B × P` feature matrix.
   Solve `(F_r F_rᵀ + ε I) W_r = F_r Z_rᵀ` for all `C` columns at once,
   with `ε = 1e-10 · tr(F_r F_rᵀ) / B`.
3. **Vectors, per group `r` and `b = 0..B−1` in order.** Form the
   residual rows `D_(r,c) = Z_(r,c) − X_(r,c)`. Set
   `M = symmetric_matrix(Σ_c w_(r,b,c) (D_(r,c) + w_(r,b,c) f_(r,b)))`.
   Replace `u_(r,b)` with the unit eigenvector of the largest eigenvalue
   of `M` (`numpy.linalg.eigh`), signed so that its largest-magnitude entry
   is positive. If that eigenvalue is not positive, keep the old vector.
   Update `f_(r,b)` and the group's rows `X_(r,·)` before the next `b`.

   This step is exact. For unit `u`, `‖svec(u uᵀ)‖ = 1`, so minimizing
   `Σ_c ‖D_c + w_c f_old − w_c svec(u uᵀ)‖²` is maximizing `uᵀ M u`.
4. **Record.** Every 10 sweeps, compute the true residual in mHa and keep
   the checkpoint with the lowest true residual. The surrogate need not
   decrease the true residual monotonically.

## Selection and gates

- A lane passes when its continuous residual is at most 19.0 mHa and its
  12-bit decoded two-body residual is at most 19.5 mHa.
- Among passing lanes, select by the complete projected 8-bit cost defined
  in `select-compressed-chemistry-shape`. `structural-rank.csv` covers only
  preparation and rotation costs, so it is not used for selection.
- If no lane passes, record each lane's terminal residuals and its outcome
  under the shared rule (`budget_limited` if still improving). This change
  ends there with no further lanes.

## Handoff

Export the selected vectors and weights, the residual trace, and both
residuals to `promote-compressed-chemistry` in the strict NPZ layout.
