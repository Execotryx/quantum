## Why

The certified direct-phasing hybrid scores 1.286176112637598 locally. The
next research cycle can replace any of its three components. The current
release path embeds the existing chemistry dimensions, allows inherited
chemistry only in an inverse-square-root successor, and uses a reduced
metric smoke sample that cannot certify the DQI confidence bound. The new
research needs scoped, reusable verification before any changed component
can be released.

## Scope

- Pin the certified archive, backend, metric, contracts and current
  reference costs as the common control for three independent workstreams.
- Add candidate-specific verification expectations, useful development
  screening, and checked confirmation and inheritance for the components
  actually changed.
- Add a source-reconciled archive preflight and integrate qualifying
  component results through deterministic local release builds.
- Coordinate [DQI](../prototype-qubit-first-dqi/proposal.md),
  [chemistry](../screen-dfthc-refactorization/proposal.md) and
  [inverse square root](../screen-compact-invsqrt/proposal.md). Research
  can begin in parallel, using the same accepted control.

This proposal plans local work. External submission, team changes,
publication, borrowing third-party artifacts and paid cloud execution
are separate decisions.
