# Design

Keep the existing fail-closed validator and candidate/release gates. Every resolved
field names an acquired file, its SHA-256 and the defining source symbols. Pin
supplementary sources when one definition spans files. Record exact executable
behavior when prose differs, retaining the discrepancy and its rationale.

Retain baseline acceptance/profiles as unresolved until a complete unmodified
official execution returns actual counters and costs. A bounded smoke result is
never full coverage. Keep upstream assets and complete snapshots under ignored
vendor paths; commit their hashes, evidence summaries and explanations only.

Use OpenSpec to track the reconciliation work. Review simplicity and performance
after implementation, then validate changed Python files with Pyright, run the
relevant tests and preserve a dated change log.
