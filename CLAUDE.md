# Project guidance

The Codex operations plugin in `plugins/quantum-operations` uses a separate frozen
MCP environment and the existing project environment for Linux jobs. Preserve
credential-free startup, previewable cloud actions, durable process identities,
and explicit review of backend path relocation. See `docs/quantum-operations-plugin.md`.
Keep `tools/provision-quantum-cloud.sh` aligned with the plugin's VM configuration
and test its preview and rerun behavior with a mocked CLI.

The inverse-square-root screen lives in `tools/invsqrt_opportunity.py`. Preserve
the preregistration, all lane outcomes, and separate full and confirmation receipts.

On the combined optimization branch, `tools/banked_chemistry.py` screens the
lookup-only replacement and tests the extracted combined archive. Preserve the
pinned numerical inputs and separate chemistry confirmation evidence.

Step-3 tools under `tools/` bind differential and primitive evidence to pinned
upstream hashes. Keep fixture coverage and expected mutation diagnostics explicit.

Follow `AGENTS.md` for contract provenance, measured gate boundaries, official DQI
failure-counter mappings, Python 3.13/WSL validation and dated change logs.

Baseline campaigns additionally require clean committed source, preregistered
A,A,B salts, an external process-tree sampler, and verified deterministic bundles.
See `docs/baseline-campaign-02-11-2026-01-19-10.md` for measurement definitions.
