# Exact radius-one DQI composition

Added a reduced `(m=63,n=2)` decoder as a composition check. For a supported single error `e` at position `j`, the pinned syndrome convention gives `S1=e*X` and `S2=e*X^2`, so the normalized locator is `1+(S2/S1)z`. The clean subtower inverse maps zero to zero, covering the zero-error case. The circuit computes the locator and derivative reciprocal, applies the existing runtime-mask phase scan, then uncomputes the reciprocal, erases the locator product with conditioned Clifford repair, and clears the remaining scratch. The first syndrome serves directly as the evaluator coefficient.

The native fixture covers the zero case and all 63 positions with varying magnitudes and masks, checks phase, input restoration and clean scratch, and passes the pinned verifier on a 2,560-shot development run. The static count is 1,911 Toffoli-like operations. Focused WSL tests, Ruff and Pyright passed. This is a correction-radius-one construction with a direct formula, not a general routed BM decoder, full-degree reciprocal, candidate admission, or full-size verifier result.

A separately registered matched development pair used the same 2,560 generated cases at (63,2). Both the pinned reference and candidate reported zero value and phase errors. The reference used 238 declared qubits and mean 77,432.201 Toffoli-like operations; the candidate used 131 qubits and mean 1,911. The registration, frozen circuit hashes, case hash and separate receipts are in docs/evidence/dqi-degree1-20261108/. This reduced-shape result does not qualify the full benchmark.
