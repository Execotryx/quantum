# D4 full-grid native verification

Both independent builds produced the same 818,415,490-byte circuit with
SHA-256 `a44bdf032e965707cc1d07228258eb07786f9d1b07e094a5d90d1f2fb4b4bff5`.
The circuit uses 4,081 qubits and 3,243,349 static Toffoli-like gates.
The first native build took 3 minutes 54 seconds and recorded peak RSS
of 3,246,008 KiB.

The official simulator reproduced the four banked D4 phase errors in
the original batches. The repaired circuit cleared all four across
1,024 shots with zero value, phase, mask or scratch errors. The
constructed pole inputs also passed all alternate masks under both
simulator seeds. The banked control reproduced five phase errors under
each seed. The regular tail tests distinguish valid singular weight-34
charts, which use the linear seed, from the solved weight-35 charts.
The portable moment guard checks included 60 logical executions with
degree, denominator, syndrome and polynomial mutations.

The preflight registered eight fresh salts after both build hashes and
the exact four replay batches passed. The full-strength pricing results
will be recorded separately.
