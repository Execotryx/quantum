# D4 tail phase repayment and explicit rejection

The previous full-weight circuit retained all three seed words
while recomputing the tail solver on the inverse. The new emitter
measures those words in the X basis after unsynthesis and frees
them. The same field products that prepared n₁, n₂ and d₁ apply
their corresponding classical phase masks during replay. Both
the regular determinant solve and the linear fallback use the
same output interface. The field-product phase evaluates the
inner product with the measured mask, including each additive
contribution to the slope.

The preparation defers seed-word allocation until after the
determinant inverse is available. Both directions release the
collapse bits while the unchanged second heads still determine
them. A zero derivative inverts to zero and the coordinate
change is invertible, so testing the restored second head for
zero recreates exactly the same bit. The incoming pole flags
stay live. The solver restores the collapse controls before
the next stage consumes them.

The final variant gates the two determinant terms while
constructing them. A mixed chart therefore enters the solver with
determinant zero. The admitted inversion maps zero to zero, which
disables all regular outputs. This uses the existing singular
predicate to select the linear fallback and removes the masked
copy of the inverse during coefficient preparation.

The shared emitter also exposes a rejection output for callers
that reserve a wire for it. It XORs the wire on a nonzero input
without a certified residual scan. The raw zero-syndrome guard
uses bounded chunks and is reversed from the restored input.
Zero receives its correct trivial phase with a clean marker.
The unsupported mixed full-weight control receives the shared
projection phase and a set rejection wire, regardless of
whether that phase happens to match its expected value.

## Linked verification and price screen

The native test checked the reconstructed polynomials and the
residual phase on 15 supported rows, including three unpadded
regular weight-35 controls. The mixed weight-35 control set
only the rejection output. The accepted and zero-syndrome
inputs left that output clear. All rows restored the syndrome,
masks and work registers at both simulator seeds. The separate
tail test repaid a measurement fingerprint with a regular
zero-denominator jet and an unsupported mixed-chart jet.

| Previous determinant solver | 1,039 | 491,617.76 |

The revised circuit saves 28 declared qubits and pays about
3,511 additional executed gates per shot. The native builder
counted 1,011 peak live qubits and 504,544 static Toffoli-like
gates. The route is still about
155,987 gates above the 1,011-qubit budget at minimum
repetition. At the measured gate count the reference price allows
at most 836 qubits, fewer than the 840 syndrome wires. The explicit
rejection makes the tested unsupported
branch observable. Exact residual phase for mixed full-weight
inputs, full matched batches, and official pooled pricing remain open.
