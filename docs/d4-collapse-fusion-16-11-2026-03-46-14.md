# D4 collapse arithmetic fusion

The compact extraction previously materialized a masked denominator
at every noninitial paired transfer. For a collapse bit c, the first
value update was N += h₀D + c·qD and the derivative update was
W += h₀′D² + c·D². Both now use the existing first-head products.
The circuit temporarily adds c·q(γ) to the value input at the
target node γ, and separately adds c to the slope input because
q′ = 1. These adjustments use CNOTs and are removed after the
corresponding product. The unit case still uses additions alone.

The inverse of a compact collapsed synthesis fold adds qD to the
reconstructed numerator. This term is now combined with h₀D inside
the existing polynomial product. At each interpolation point t,
the circuit temporarily adds c·q(t) to the constant coefficient
used to query the head. The added term has zero residue modulo q,
so it changes only quotient coordinates. The in-place residue
scale still uses the original head. When the tight layout admits
a collapse, the highest D slot is zero and the same point count
is sufficient. In a wider layout, the emitter includes the extra
point. An overflow can alias into lower interpolated coefficients,
but the exact same XOR is undone on reversal, and the live layout
guard disqualifies the branch from applying residual phase.

## Static gate reduction

The sixteen external extraction chains contain 120 noninitial
paired transfers per traversal. Four traversals lose 24 masked
AND computations per transfer, removing 11,520 gates. The scalar
tail replay removes another 384. The sixteen tight synthesis
pairs lose 6,528 gates across both directions. The expected total
reduction in the shared circuit is 18,432 static Toffoli-like
gates. The native builder confirmed the count fell from 495,188
to 476,756. The outer projected fold uses its existing correction.

checks cover both field widths, the scalar and derivative paths,
and both collapse values. The fold controls cover finite and
collapsed synthesis with phase repayment. A separate test forces
a nonzero high slot on a tight collapse, observes one recorded
violation, applies a phase fingerprint, and verifies exact input
restoration and scratch cleanup at two measurement seeds.
