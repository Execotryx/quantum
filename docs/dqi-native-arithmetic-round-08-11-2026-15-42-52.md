# Native routed BM arithmetic round

The three-word arithmetic fixture now computes the syndrome convolution into a clean discrepancy register, computes `alpha=Delta*sigma_0` and its zero-safe inverse, conditionally selects the multiplier, routes the locator and shifted template, and applies the shared product-XOR. The branch bit and shifted template are coherent caller inputs. The old locator constant is copied into scratch before routing and erased from the appropriate output row, avoiding two additional controlled-selection networks.

The forward round stores `Delta` in the caller's initially zero history word only on retain; zero discrepancy leaves the word zero. On replace, the updated locator's constant coefficient is `1/Delta`, so a clean inverse conditioned on the branch reconstructs and clears the transient discrepancy. On the inverse pass, the retained word or the replace locator reconstructs the discrepancy; the routed adjoint restores both rows, the retain history is cleared, and the original syndrome convolution clears the discrepancy. The branch input must be false for zero discrepancy, and the forward shifted template must have zero constant coefficient. These are explicit preconditions, not checks emitted by this slice.

The three-word forward and reverse circuits each use 948 Toffoli-like gates and 220 declared qubits. The intermediate multiplier/update-only fixture uses 558 Toffoli-like gates and 160 qubits. Receipts with circuit hashes are under `docs/evidence/dqi-arithmetic-round-20261108/`. Native tests use coherent branch, discrepancy and register inputs, exercise zero/retain/replace cases, compare with independent field arithmetic, and check phase, input restoration, history and all scratch. The inverse is a separately emitted composition; the test does not claim a native proof for all possible superpositions beyond the verified reversible identities. Focused WSL tests, Ruff and Pyright passed.

Age and counter updates, coherent branch calculation, shifted-template routing and cleanup, indexed history management, unrolling, a general degree-35 reciprocal and full decoder assembly are not implemented by this fixture. No full-size cost, admission or confirmation follows from it.

A subsequent three-word composition computes the replace bit coherently from the nonzero discrepancy and the sign of the caller's signed counter. It updates the counter as d -> -d on replace and d -> d+1 otherwise, and the reverse restores the old counter, rows, history and initially zero branch bit. The shifted template remains supplied externally; the caller must prevent counter overflow and satisfy the forward support preconditions. Reusing the already computed discrepancy for branch selection avoids two redundant convolutions, saving 324 Toffoli-like gates in this three-word configuration. Forward and inverse each use 983 Toffoli-like operations at 224 declared qubits. Native tests exercise zero, retain and replace cases with signed counters, phase and scratch. The earlier arithmetic-only KMB hash remained unchanged after factoring common operations. Counter-round receipts are alongside the arithmetic receipts; the focused tests, Ruff and Pyright passed.
