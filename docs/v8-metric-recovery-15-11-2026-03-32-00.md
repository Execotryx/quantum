# v8.0 metric run recovery

The first cloud metric reached the routed DQI verifier after completing
inverse square root. DQI's temporary circuit serialization failed while the
VM had 361 MiB available for a 617 MiB KMB. The worker exited before it
could write a completed metric or DQI receipt. The driver's generic
`no_go` record in this attempt describes the incomplete run. The stderr
shows the file-write failure.

The exact failed receipt set remains under
`docs/evidence/v8/v8.0/attempt-1/`. The retry uses the original archive,
registration and metric salt in a fresh output directory. Before starting,
the VM reclaimed disposable extracted copies from the failed attempt and
the completed v6 run. Available disk rose to 3.1 GiB. The original ZIPs,
registrations and verifier reports remain available.

The follow-up Ubuntu run passed all 46 focused tests. Ruff and Pyright
passed for the project's changed Python files. Strict OpenSpec validation
passed for all seven changes in this set.
