# v8.0 upload evidence

The v8.0 receipt reader now checks both full verifier receipts and their
original request hashes before accepting an external score. Each role
must bind the staged ZIP through its preflight, use its registered salt,
and complete the full verifier coverage on the pinned metric. The reader
recomputes the aggregate from the measured costs and checks both the
registered score band and the retained component costs.

The same evidence check can run before upload. The regression test
reconciles a hash-bound listing and rejects confirmation preflight
evidence that names a different ZIP.
