# DQI stage profile and product erasure

The reference stage profiler snapshots the native circuit at the reference emitter's existing marked boundaries. Its per-stage operation totals use the same native `num_toffoli_like` statistic as the pinned verifier. It rejects an unexpected method/stage or mark, a gap between stages, totals that do not reconcile, and any mismatch between its KMB bytes and a separately built reference. The native builder does not expose per-call counters: boundary snapshots avoid quadratic copying. Width is observed after proxy calls, so transient native allocations are not represented. The product census counts direct builder calls; native internals are not expanded. Full-shape profiling, process-tree PSS, matched executed-count reconciliation and the build-order decision remain open.

Reduced receipts are in `docs/evidence/dqi-stage-profile-20261108/`. The (63,4) reference contains 107,341 static Toffoli-like operations at 286 declared qubits, with 78.93% in the locator and 20.82% in the scan. The (127,12) reference has 308,781 at 484 qubits, with 84.61% in the locator and 14.72% in the scan. These figures do not establish full-shape proportions.

The product erasure measures a fresh product in the X basis and applies measurement-conditioned CZs from the pinned GF(4096) polynomial multiplication tensor. For each basis pair and each measurement bit, the CZ exponent equals that output bit of the product; bilinearity extends this identity to all input superpositions and measurement outcomes. The implementation groups CZs by outcome to reduce condition overhead. A native circuit fixture covers all 144 basis pairs, dense random pairs and clean scratch; a deliberately omitted CZ produces a phase error. This is a primitive only; no exact routed locator, phase-only scan, or candidate admission is claimed.

WSL Python 3.13 focused tests passed (two profiler and three erasure tests); Ruff and Pyright passed on the new Python files. The three DQI OpenSpec changes validated strictly. No full-size or confirmation result was generated by this local work.

A separate 36-case classical fixture compares Forney recovery and the trace-dual runtime-mask identity at every supported weight, including zero, with zero, dense and seeded masks. It passed in WSL with Ruff and Pyright. This does not prove or implement the reciprocal-based scan.
