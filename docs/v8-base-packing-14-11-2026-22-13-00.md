# v8.0 base archive packing

The v8.0 driver verifies the v6 parent receipt and the routed DQI
registration, full verification and fresh confirmation before selecting
members. The retained v6 inverse-square-root and chemistry artifacts come
from the verified parent ZIP.

The packer preserves the existing stored format. The DEFLATE option pins
the runtime and Python build, uses level nine and orders members exactly
as in stored mode. The upload byte limit is recorded as unknown, so the
driver selects DEFLATE for v8.0. It checks the stored and compressed
extractions against the same manifest and requires matching independent
archive builds.

The stored regression reproduced the v6 ZIP exactly. For v8.0, the
stored container was 640,659,514 bytes and DEFLATE was 57,175,328 bytes.

`b93301f01cd5f4b3fba90d0cdff64c302ce4686adeb25f894f2a893cabffa377`.

2.6228156034. The registration binds both fresh salts and the member
