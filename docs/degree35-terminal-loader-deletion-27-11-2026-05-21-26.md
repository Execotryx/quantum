# Exact product deletion screen for the terminal ANGLE loader

The Google Cloud run replayed goodpjw2008's 206-gate v221 slot 14 on all **1,219 addresses** from each original endpoint. It reproduced the expected word values and clean scratch in the value replay. The source has **285 free angle words** in the terminal packet. The dependency census found **82** protected products and **124** whose effects reach the final word wires only through linear operations. Each independent product had the same Boolean value function on both original endpoints. [Pinned source and attribution](degree35-zero-angle-loader-research-27-11-2026-05-12-36.md) · [Cloud receipt](evidence/aggregate36-20261126/chem-v221-terminal-product-deletion-cloud.json)

For each word, the screen projects all product functions onto the addresses where that word is constrained. It solves for the existing nonlinear contribution to each of the seven bits. The cache and product truth functions are frozen. The solver permits arbitrary fan-out coefficients and adds 93 pure address indicators, covering all functions of the high address alone or low address alone. It derives a null-space basis alongside the GF(2) reduction. A column is required if some output needs its coefficient and no null-space direction can change that coefficient.

**All 124 independent products are indispensable** even under those relaxed forward conditions. Every smaller subset fails as well. This rules out deleting these products by reassignment and linear recombination within this dictionary. Layouts with different product controls, caches, or loader boundaries need their own evidence. The proof produced no lower-cost emitted circuit, and the v221 slot remains at **206 static Toffoli-like gates**. [Screen implementation](../tools/chem_product_deletion.py)
