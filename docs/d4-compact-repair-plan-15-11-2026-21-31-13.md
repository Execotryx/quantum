# Compact D4 repair plan

Astra reviewed the full-grid repair receipts and both decoder implementations.
The measured homogeneous groups 1–7 ablation is the starting control for
a compact local-pole fold. It fixes three of four original failures at
904 qubits. The current repair fixes the fourth, but its simultaneous
coefficient and certificate banks and its per-point inversion scan
account for much of the cost increase.

The plan derives a reversible doubled-node absorption using existing
syndrome storage and preserves D4's projected-mask and streamed conversion
contract. It uses the two fresh full-grid value errors as exact replay
targets because their cause remains unresolved. The first implementation
gate is one complete fold with an inverse and phase tests. Resource
screening uses the pinned pooled metric before any new full campaign.
The open-circuit options include scalar gauge replay from D4 and Q880
as a source-admitted comparison or kernel reference.
