## Chemistry endpoint compatibility resolved

The pinned `vendor/official/verifiers/dfthcsos/scoreinfra/circuits.py` hash is `fc027b52fdcebe14404f403a089122485d097ed65d03e6d989623d620b1ab68c` (checked). Its prose describes a general XOR oracle, while `recover_words_from_circuits` at lines 534–555 simulates the actual forward/reverse reachable word states. It resets scratch between circuits, restores the previous/current batch, and checks selection, workspace and phase after every call.

The source's `verification/prove_loader_branches.py` proves exactly those two endpoints, for all 1,220 valid addresses and every symbolic HMR outcome. It independently sets each erased Boolean function as a measurement-phase coefficient and requires all coefficients to vanish. It checks the words and scratch, but does not prove arbitrary target-register behavior.

This limitation matches an explicit live clarification in [topic 753092](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation/discussion/753092), message 3545739, dated 2026-10-27 19:12:57 UTC. The answer says the required domain is the reachable forward/reverse states for valid addresses, rather than arbitrary target inputs; the subsequent discussion attributes the ruling to Tanuj. Later [topic 757522](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation/discussion/757522) repeats the question but contained no contrary ruling when checked. Therefore the endpoint-only implementation is compatible with both the actual published verifier and the located clarification. Keep the proof's restricted scope explicit rather than claiming arbitrary-z XOR equivalence.

Additional chemistry checks remain numerical and native: decoded one- and two-body residuals <=20 mHa, raw Lambda>49, E_gap>3.914898, valid SOS gap, correct register widths, no phase rotations, and each ANGLE<=128 qubits. The source build does not run the official chemistry verifier; its `VERIFIERS_DIR` argument is accepted but unused. Full verification is required after build success.
