A fresh extraction matched every registered member. The inverse-square-root full-domain proof and chemistry endpoint proof passed during the rebuild.

The first two launch attempts exited before emitting a circuit. The first selected the wrapper directory above the DQI source root. The second reached the emitter with the official engine and verifier absent from the paths required by the upstream manifest. The completed attempt selected the source root and staged the hash-checked engine and verifier at those paths.

## Cloud verification

The pinned competition metric scored the archive **26.78302388** on Google Cloud. An independent confirmation using a fresh extraction and a distinct registered salt scored **26.78303192**. Both runs completed 200,540,928 inverse-square-root trajectories, 102,400 DQI trials and 78,080 chemistry checks. Both DQI runs recorded zero verifier failures.

The first cloud launch exited before simulation because its extraction path passed through a symlink. The retry used the physical path and retained the registered archive, metric and salts. The downloaded receipt archive matched the VM's SHA-256, and the certificate audit recomputed both aggregate scores from the retained verifier costs. The release handoff binds the confirmed DQI bytes to their original pooled qualification record and the full archive.
