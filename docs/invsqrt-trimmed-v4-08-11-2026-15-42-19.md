# Trimmed inverse-square-root development lane

The certified control is the 28/20/14 lattice KMB
`c487332fe965389191c8e6d34848d61c82748e5802c6e616eb0363869f92c4c9`,
with cost 509,471.48180735623. The frozen table's coefficient maxima are
268,435,454, 524,275 and 6,084, fitting 28, 19 and 13 bits respectively.
The opt-in circuit removes those three high coefficient bits and the unused
integer bit from the 39-bit output. This also narrows scratch and arithmetic.

A native slice price, produced before candidate emission, predicted 150 qubits,
2,908 Toffoli-like gates and complete cost 472,336.9178780867, a 7.29% gain.
The actual serialized candidate had those counts and cost. Its SHA-256 is
`f4c8503d87c9e7cedb8a79a796e0b195623c2e88467691ca1b08af1a70fb200d`.
Two independent builds reproduced the same KMB. Binary artifacts remain in
ignored `runs/`; the preprice, input hashes, source hashes, separate build
receipts and v4 control trace are under
`docs/evidence/invsqrt-trimmed-v4-20261108/`.

The development model checked all 3,133,452 inputs, every partial Horner
subtraction, the shifted output high-bit bound and phase-word equality with the
frozen control. The model reproduces the control's margin and witnesses:
66.77% worst tolerance use, no failures. Native fixtures checked 31,232 shots
across 7,806 inputs, including segment edges, powers of four and both margin
witnesses; input and scratch restoration and phase parity passed. A table
mutation that sets a removed high bit is rejected. These native trajectories
are sampled development evidence, not a formal branch proof or full verifier.

The control tracer samples public builder calls; native transient allocation
inside a call is opaque, and the serialized first/last interval overlap is a
conservative upper bound. The width result is based on actual emitted resource
counts, not the public-allocation peak alone.

The subsequent [campaign registration](evidence/invsqrt-trimmed-v4-20261108/verification/screen-registration.json)
pinned the clean source, built the v4 control first and reproduced the
candidate twice. The [full pass](evidence/invsqrt-trimmed-v4-20261108/verification/full-result.json)
and [fresh confirmation](evidence/invsqrt-trimmed-v4-20261108/verification/confirmation-result.json)
each completed 200,540,928 trajectories at 472,336.9178780867 with
66.77% worst tolerance use. Both report the exact same circuit hash and
have separate registered salts. The remaining promotion gate is the
paired archive with the original DQI, chemistry circuits and NPZ.
See [campaign tasks](../openspec/changes/trim-invsqrt-known-zero-bits/tasks.md).

Targeted native and bounds tests, Ruff, Pyright with the pinned Ubuntu
interpreter and strict OpenSpec validation passed.
