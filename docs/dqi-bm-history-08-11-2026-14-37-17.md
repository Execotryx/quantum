# Exact normalized BM history fixture

The classical fixture writes normalized `C` and `T = z^offset B / previous_discrepancy`, with `C[0] = 1`. Each round computes `Delta` from `C` and the syndrome prefix, and updates `C_new = C_old + Delta*T_old`. Retain sets `T_new = z*T_old` and saves `Delta`; replace sets `T_new = z*C_old/Delta` and updates the degree to `r+1-L`.

On a replace round, `T_new[1] = 1/Delta`, so the inverse reconstructs `Delta`, recovers `C_old = Delta*T_new/z`, then recovers `T_old = (C_new+C_old)/Delta`; the old degree is `r+1-L_new`. On a retain round, it takes `T_old = T_new/z` and reconstructs `C_old = C_new+Delta*T_old` using the saved discrepancy. Both paths recheck the recurrence and branch condition, and the complete inverse must restore the initialized state. A changed history entry was found capable of producing another locally consistent inverse trajectory; the final initialization check detects it. Thus these checks are development diagnostics, not a replacement for history integrity in the eventual reversible circuit.

The fixture agrees with the existing BM oracle and restores its initial state for one deterministic error vector at each weight 0–35; it tests history mutation. In particular, for 70 zero syndromes this recurrence produces `T = z^71`. Therefore a 35-word auxiliary cutoff cannot be justified for this straightforward representation; any finite-width routed version needs a separate representation and exact liveness proof. This does not prove the proposed Gu-style rescaling or its `sigma_0*delta=1` invariant and does not implement the routed locator. All 38 focused WSL tests, Ruff and Pyright passed.

A further exhaustive GF(16) fixture enumerates all 65,536 four-symbol syndrome sequences. It compares every prefix with a separate standard BM recurrence and reverses the complete history; 39 focused tests now pass in WSL, together with Ruff and Pyright. This establishes the classical recurrence on those small inputs only, and does not bound its auxiliary width or implement the routed representation.
