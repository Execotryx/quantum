# Registered S2 command

`tools/chem_s2.py` now supplies a supervised S2 command. It requires pinned
paths and SHA-256 values for the reference factorization, S1 registration,
S1 terminal decision, S1 checkpoint receipt and continuous checkpoint NPZ.
The terminal decision must say `go`; its evaluation count and residual must
match the checkpoint receipt, which must identify the checkpoint bytes. The
worker independently reconstructs the shifted target, checks its registered
SHA-256, and recomputes the checkpoint's continuous residual at 19.0 mHa.

For a future qualifying S1 checkpoint, prepare a JSON plan with keys
`factorization`, `s1_registration`, `s1_decision`, `s1_checkpoint_receipt`,
and `s1_checkpoint`; each contains `path` and `sha256`. Supply `target_sha256`,
`brot`, and `limits` containing `evaluations`, `restore_evaluations`,
`wall_seconds`, `checkpoint_interval`, `outer_iterations`, `offset_bound`,
and `penalty`. Run `python tools/chem_s2.py run PLAN OUTPUT` from the checkout
using the frozen Ubuntu environment and a fresh output directory. The command
uses the process-tree supervisor and records execution status separately from
the worker's scientific decision. `python tools/chem_s2.py target FACTORIZATION
OUTPUT_JSON` computes a target pin before a plan is registered.

The current factorization's [target pin](evidence/chem-s2-target-20261108/target.json)
is SHA-256 `7e72455f4f6e6a476fed9c1626a96cebea775c4fc071145fd056af23d63e8393`,
over the C-contiguous 2926-by-2926 little-endian float64 packed shifted
target. This pin does not confer S1 eligibility. Each S2 checkpoint retains
separate hashed continuous arrays, strict NPZ, decoded words, and exact
metrics. A best eligible checkpoint identifies its directory; this is still
development evidence and is not a release or cost-improvement claim.

Synthetic worker integration tests exercise the success path with a mock
evaluator, immutable pin mismatches, and exact checkpoint hashes. Separate
tests use pinned evaluator math for decoding, and the CLI rejects the real
budget-limited S1 pilot before creating an output directory. No current S1
pilot passed the gate, so no production S2 run was performed.
