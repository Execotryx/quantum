# Hybrid optimization implementation

The v3 inverse-square-root registration adds independent binary normalization,
phase-corrected measurement unlookup and a precision ladder. The previous circuit
builds remain explicit controls. A combination runs only after its constituent
changes pass independently and reduce the complete control cost.

The DQI experiment replaces the controlled multiplication inside the pinned
EEA schedule with a deterministic tower-field product. A classical Forney
oracle and matched serialized decoder checks provide independent development
coverage. Reduced shapes have separate receipts from full-size verification.

The chemistry experiment ranks 384 layouts, then evaluates a bounded continuous
pilot with the shifted symmetric Gram objective and a streamed residual. The
numerical gate controls whether decoded-word evaluation and synthesis proceed.
